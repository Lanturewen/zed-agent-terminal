# Asset and redistribution notice

`assets/AgentIcons.ttf` is included because it is required for the local
terminal text fallback used by this integration. The font was present in the
author's local macOS font directory when this package was assembled. Before
redistributing this package publicly, verify the license and provenance of the
font and the underlying agent artwork against the upstream projects.

The shell wrapper and installer are independent glue code. They do not install
or redistribute Codex, Claude Code, Antigravity, Grok, Pi, or Zed. Each agent
must be installed separately under its own terms.
